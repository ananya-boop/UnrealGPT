# UnrealGPT

Talk to your Unreal Engine.

UnrealGPT is an AI-powered assistant that understands natural language and performs editor actions inside Unreal Engine.

## Example

You:
> Create a cinematic sunset beach.

UnrealGPT:

✓ Creates a new level

✓ Builds a landscape

✓ Creates an ocean

✓ Configures Sky Atmosphere

✓ Sets the sun angle

✓ Adds volumetric clouds

✓ Scatters palm trees

✓ Creates cameras

✓ Generates a Level Sequence

✓ Starts Movie Render Queue

All from one prompt.
