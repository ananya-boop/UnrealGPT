# UnrealGPT

## Vision

UnrealGPT is an AI-powered assistant that allows artists, technical artists, and developers to control Unreal Engine using natural language.

---

## Mission

Reduce repetitive work inside Unreal Engine through AI-powered automation.

---

## Goals

- Build scenes using natural language.
- Automate repetitive editor workflows.
- Assist artists instead of replacing them.
- Be extensible through tools.
- Support multiple AI providers.
- Be open source.

---

## Non Goals

- Not replacing Unreal Engine.
- Not generating games automatically.
- Not replacing artists.
- Not modifying engine source.

---

## Target Users

- Unreal Artists
- Environment Artists
- Technical Artists
- Unreal Developers
- Pipeline TDs
- Virtual Production Teams

---

## Example Commands

Create a sunset beach.

Create an abandoned city.

Import every FBX in this folder.

Create cameras around the subject.

Render the sequence.

Find duplicate assets.

Fix redirectors.

Optimize this scene.

---

## Core Principles

The AI never writes Unreal code directly.

The AI only calls registered tools.

Every tool should be reusable.

Every action should be explainable.

The system should support multiple AI providers.
